【第 A 段】G-06 数据库直查（只读 SELECT，不改任何数据）
--------------------------------------------------------------------------------
背景：is_deleted / deleted_at / deleted_marker 这三个字段接口刻意不对外暴露
      （这是正确设计），所以「deleted_at 非空」必须直接查库确认。
================================================================================


-- A-1 主查询：列出 acctest01 的全部目标，并把「deleted_marker 是否等于 id」直接算出来
SELECT g.id, g.goal_type, g.target_value, g.status, g.is_deleted, g.deleted_at, g.deleted_marker, (g.deleted_marker = g.id) AS marker_equals_id FROM health_goal g JOIN user_account u ON u.id = g.user_id WHERE u.username = 'acctest01' ORDER BY g.goal_type, g.id;


--------------------------------------------------------------------------------
A-1 看到什么算通过：共 5 行，goal_type 依次为  sleep, sleep, sport, water, weight
--------------------------------------------------------------------------------

goal_type        is_deleted  deleted_at                deleted_marker  marker_equals_id
---------------  ----------  ------------------------  --------------  ----------------
sleep(较小 id)   1          非空(如2026-09-14 12:2x:xx) 等于该行 id     1
   ↑ ★ 这就是被软删的那条旧记录：
       · is_deleted = 1                     → 已软删
       · deleted_at 非空                    → 软删时间已写入
       · deleted_marker = 该行 id           → ★ 关键，必须等于自身 id（不能是 0 或别的值）
       · 该行仍能被查出来                    → ⇒ 物理行未被删除

sleep(较大 id)   0          NULL                      0               0
   ↑ ★ 这就是软删后「同类型立即重建」出来的那条新记录，
      靠 id 与 is_deleted 与被软删的那条明确区分。

sport            0          NULL                      0               0    （target_value = 150）
water            0          NULL                      0               0    （target_value = 2500，被③修改过）
weight           0          NULL                      0               0    （target_value = 66.0）

提示：浏览器 Console 汇总区会打印「被软删的 sleep 目标 id」与「重建后的 sleep 目标 id」，
      可与本表逐行对齐。


-- A-2 只看软删行的等价查询（可选，同样只读）
SELECT g.id, g.goal_type, g.is_deleted, g.deleted_at, g.deleted_marker, (g.deleted_marker = g.id) AS marker_equals_id FROM health_goal g JOIN user_account u ON u.id = g.user_id WHERE u.username = 'acctest01' AND g.is_deleted = 1;


--------------------------------------------------------------------------------
A-2 看到什么算通过：恰好 1 行
--------------------------------------------------------------------------------
is_deleted = 1 ；deleted_at 非空 ；deleted_marker 等于该行 id ；marker_equals_id = 1


-- A-3 退出 MySQL
exit
