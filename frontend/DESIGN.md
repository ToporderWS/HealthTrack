## 1. 落地方式（三层，硬规则）

### 1.1 三层分别是什么、落在哪里

| 层 | 文件（落点） | 内容 | 说明 |
|---|---|---|---|
| **① 定义层** | `frontend/uni.scss` | 全部 Token 的 **SCSS 变量**（`$c-p-600: #0A7A6D;` …） | UniApp **自动注入**每个 SFC，组件内**无需 import**；字面值只写在① |
| **② 运行时层** | `frontend/App.vue` 的 `<style>` | `page` / `:root` 上的 **CSS 自定义属性**（统一形如 `--<Token 名>: #{$<同名 SCSS 变量>};`）+ **全局重置**（页面底色、字体栈、`tabular-nums`、盒模型） | 把①的 SCSS 变量转写成运行时变量；**本层不写新字面值**，只做 `$x → #{$x}` 转写 |
| **③ 消费层** | `frontend/components/**`、`frontend/pages/**` | 只允许 `var(--x)` 引用；SCSS 场景可写 `$x`（由①注入） | **不得**出现任何字面值 |

### 1.2 引用关系（**单向，不得反向**）

```
① uni.scss  ——— 唯一字面值来源（$ 变量）
      │  App.vue 的 <style lang="scss"> 内以 #{$x} 引用
      ▼
② App.vue  page / :root 的 CSS 自定义属性（--x）——— 运行时唯一真相源
      │  组件与页面统一 var(--x)
      ▼
③ components/**.vue、pages/**.vue ——— 纯消费，零字面值
```

### 1.3 硬规则

1. 同一 Token 的**字面值只写在①**；②只做 `--x: #{$x};` 转写。
2. ③ **禁止**出现裸 HEX / 裸 rgba / 裸字号 / 裸间距 / 裸圆角 / 裸阴影（含 `scale()` / `opacity` 等比例值，见 §7）。
3. ②中**不得新建**未在 §2~§7、§10 登记的 `--x`。
4. 唯一豁免文件 = `uni.scss` 与 `App.vue`；**豁免文件内也只写 Token 定义与全局重置，不写页面样式**。

**图标 / 插画**：`static/` 当前为空。图标方案**待拍板**（见报告 §28.2）；空状态与失败态**不使用插图库**，用几何构成。

## 5. 圆角（Radius）

**① Token 定义**

| Token | 值 | 角色 | 用于 |
|---|---|---|---|
| `--r-xs` | `8rpx` | 最小档 | 标签 / chip / 角标 |
| `--r-sm` | `12rpx` | **次级圆角** | 输入框 / 小按钮 / 开关槽 |
| `--r-md` | `20rpx` | **★ 默认圆角** | 卡片 / 主按钮 / 选择器 / 列表卡 |
| `--r-lg` | `28rpx` | 大容器档 | 大卡片 / 弹层 / 分组容器 |
| `--r-xl` | `40rpx` | **★ 最大圆角（上限）** | 底部抽屉顶两角 / 全屏弹层 |
| `--r-full` | `999rpx` | 全圆语义 | 胶囊 chip / 开关 / 进度环 / 圆点 |

**② 强制规则**

1. **默认圆角 = `--r-md` = `20rpx`**（页面上的"没有理由时的选择"）。
2. **上限 = `--r-xl` = `40rpx`**，任何元素**不得**超出此档。
3. **同一屏最多出现 3 种圆角档位**。
4. **嵌套容器内层圆角 ≤ 外层圆角**（例：卡片 `--r-md` 内的缩略块用 `--r-sm` 或 `--r-xs`）。
5. **禁止超大气泡圆角 / 全宽大圆角卡片**。
6. `--r-full` 属"全圆元素"语义（用于**本身是圆形/胶囊**的元素），**不计入**上述 3 档统计，也**不得**用于矩形卡片。

**③ 抽屉与弹层用法**：底部抽屉只圆**顶部两角** → `border-radius: var(--r-xl) var(--r-xl) 0 0;`

## 6. 阴影（Elevation）

**策略：卡片优先靠「1rpx 边框 + 底色差」建立层级，阴影只做"离屏距离"暗示。**

**① Token 定义（每一级的具体值）**

| Token | 值 | 用途 |
|---|---|---|
| `--el-0` | `none` | **平面卡：列表卡 / 分组容器 / 输入区 ★ 默认** |
| `--el-1` | `0 2rpx 8rpx rgba(31,35,41,0.04)` | 内容卡 / 浮起小卡 |
| `--el-2` | `0 8rpx 24rpx rgba(31,35,41,0.06)` | 吸顶顶栏 / 浮起卡 / 悬浮按钮 |
| `--el-3` | `0 16rpx 48rpx rgba(31,35,41,0.10)` | 弹层 / 底部抽屉 / Toast |

```
--el-0: none;
--el-1: 0 2rpx  8rpx rgba(31,35,41,0.04);
--el-2: 0 8rpx 24rpx rgba(31,35,41,0.06);
--el-3: 0 16rpx 48rpx rgba(31,35,41,0.10);
```

**② 卡片默认组合（**不加阴影**）**

```
background:    var(--s-card);          /* 表面 Token，定义见 §2.4 */
border:        1rpx solid var(--b-line); /* 边框 Token，定义见 §2.4 */
border-radius: var(--r-md);            /* 默认圆角，定义见 §5 */
box-shadow:    var(--el-0);            /* = none */
```

> `--s-card` / `--b-line` 的**定义在 §2.4**，本节只引用；`el-` 家族的定义在**本节**。同名 Token 不设第二套定义。

**③ 硬规则**

1. **一屏最多同时出现 2 级阴影**。
2. **卡片默认无阴影**（用边框 + 底色差）；仅在需要表达"浮起"时才升到 `--el-1` 及以上。
3. **禁止彩色阴影**：阴影色只能是 **`--c-n-800`（`#1F2329`）的透明形态**（即 `rgba(31,35,41,α)`），**不得使用任何其他色相**（`--el-1`～`--el-3` 已按此登记）。
4. **禁止内阴影**（`inset`）。
5. **禁止多层叠加**（一个元素只允许一个 `box-shadow` 值）。
6. 阴影的位移与模糊半径一律用 **`rpx`**（随屏宽等比，与 §10.4 规则②一致）。

## 7. 动效（Motion）

**① 时长 Token**

| Token | 值 | 用途 |
|---|---|---|
| `--d-fast` | `120ms` | 点击反馈 / 状态切换 |
| `--d-row` | `150ms` | **列表行**按下底色切换 |
| `--d-base` | `200ms` | **弹层**淡入 / **数值**淡入 / 通用过渡 ★ 默认 |
| `--d-slow` | `300ms` | **底部抽屉**上滑 ★ **上限，不得超出** |
| `--d-toast` | `2000ms` | Toast **停留时长**（非过渡时长；`--d-toast` 后自动消失） |
| `--d-breathe` | `1200ms` | **骨架屏**透明度呼吸（循环） |

**② 缓动 Token**

| Token | 值 | 用途 |
|---|---|---|
| `--ease-std` | `cubic-bezier(0.2, 0, 0.2, 1)` | 默认（可逆的双向过渡） |
| `--ease-out` | `cubic-bezier(0, 0, 0.2, 1)` | 进场 / 上滑 |
| `--ease-in` | `cubic-bezier(0.4, 0, 1, 1)` | 退场 |

**③ 比例值固定 Token**（防止 `.vue` 内出现裸比例值）

| Token | 值 | 说明 |
|---|---|---|
| `--press-scale` | `0.97` | 所有可点元素按下缩放，**不得改用其他比例** |
| `--press-opacity` | `0.92` | 所有可点元素按下透明度 |
| `--breathe-opacity` | `0.55` | **骨架屏**透明度呼吸的最低不透明度（配合 `--d-breathe`）｜**S3-1 实施期补登，见 ⑤** |

```
--d-fast: 120ms;  --d-row: 150ms;  --d-base: 200ms;  --d-slow: 300ms;
--d-toast: 2000ms; --d-breathe: 1200ms;
--ease-std: cubic-bezier(0.2, 0, 0.2, 1);
--ease-out: cubic-bezier(0, 0, 0.2, 1);
--ease-in:  cubic-bezier(0.4, 0, 1, 1);
--press-scale: 0.97;  --press-opacity: 0.92;  --breathe-opacity: 0.55;
```

**④ 场景规范**

| 场景 | 规范 |
|---|---|
| 点击反馈 | 所有可点元素 `scale(var(--press-scale)) + opacity(var(--press-opacity))`，`--d-fast`；列表行改底色 `--c-n-100`，`--d-row` |
| 保存反馈 | 按钮立即 disabled + 内置 loading → 成功 Toast「已保存」+ 返回来源页自动刷新；「保存并继续记录」→ Toast「已保存，可继续记录」+ 清数值 + 焦点回输入框 |
| 加载 | 首屏**骨架屏**（禁整页白屏）；> 8s 追加「仍在加载，请稍候」；切维度保留旧内容 + 淡加载 |
| 成功 | `--c-success` Toast 停留 `--d-toast`；短成功可只用页面切换（不弹 Toast） |
| 失败 | `--c-danger` Toast 或 `AppErrorState` + **明确重试入口**；**绝不静默失败** |
| 页面进出 | **默认用原生栈动画**（不加自定义转场）；抽屉 `--d-slow` 上滑 + `--ease-out`；弹层 `--d-base` 淡入 + `scale(1.02→1)` |
| 数据刷新 | 返回上一页自动刷新；下拉刷新**仅列表页** |
| 数值变化 | 仅 `--d-base` 淡入；**不做数字滚动** |
| 骨架屏 | 仅透明度呼吸 `--d-breathe`；**不做扫光位移** |
| 降低动态 | 尊重系统"减少动态效果"：关淡入/缩放，仅保留即时状态切换 |
| **禁止** | 弹跳 / 弹簧 / 视差 / **> 300ms 过场** / 无状态含义的循环动画 / 连续震动 |

**⑤ 实施期补登（S3-1，2026-09-15）**

| Token | 值 | 补登原因 |
|---|---|---|
| `--breathe-opacity` | `0.55` | §7④ 已规定「骨架屏仅透明度呼吸 `--d-breathe`」，§12 又禁止 `.vue` 内出现裸 `opacity`，但 §7①②③ **原未给出呼吸的最低不透明度**，导致 C-15 AppSkeleton 无 Token 可用。按 §1.3 硬规则②「新增令牌必须先登记本文件」，在此补登。**不改变** `--d-breathe`、缓动、`--press-*` 及「仅透明度呼吸、不做扫光位移」的任何既有规则；`--press-scale` 仍为**唯一**允许的缩放比例值。 |

## 9. 图表规范

- **库**：uCharts（`qiun-data-charts`）—— S1-D 已冻结批准，**S3-4 批次安装**（建议 `uni_modules` 形式）。
- **类型**（服务端已定）：`weight` 折线 / `bp` 双折线 / `heart` 折线 / `glucose` 折线 / `sleep` 柱状 / `water` 柱状 / `sport` 柱状 / `mood` 折线。
- **颜色**：**一律使用 §2.5 的 Token** —— 单折线/柱体 `--c-chart-main`；血压双线 `--c-chart-a` + `--c-chart-b`；目标线 `--c-chart-goal`；网格 `--c-chart-grid`；面积 `--c-chart-area-top` / `--c-chart-area-bottom`；选中点 `--c-chart-point` / `--c-chart-point-ring`。**不得直接写 HEX**，**不存在第 9 个图表颜色**；8 类指标共用同一色相，靠**图标 + 标签 + 单位**区分。
- **尺寸**：宽 = `var(--chart-w)`、高 = `var(--chart-h)`（见 §10.2），**禁写死 px 宽**。
- **数据诚实性（必须）**：① 缺失日期**不插值不补零 ⇒ 折线断开**（`connectNulls: false`）；② 柱状图缺日**不画零高柱**；③ 睡眠按 `recorded_at`（起床时间）归属起床日；④ 窗口由**服务端**计算，客户端不拼窗口；⑤ 90 天用服务端聚合点，不做客户端抽样。
- **轴**：Y 轴 4–5 格；连续量可不从 0 起，**柱状图必须从 0 起**；X 轴 7 天逐日 / 30 天每 5 天 / 90 天每 15 天；横网格虚线 `--c-chart-grid`，**不画竖网格**。
- **标注**：数据标签**不常驻**，点选时用气泡 + 竖直指示线；单位由摘要卡承载；单线指标**不显示图例**。
- **红线**：❌ 红绿好坏语义色｜❌ 医学参考范围带｜❌ 颜色分级｜❌ "正常/异常/偏高/偏低"｜❌ 彩虹配色 / 多指标叠加（F-037～F-039 属 P1）。

### 10.4 适配（6 条）

1. 主尺寸一律 `rpx`（**750 设计稿基准**）。

4. 图表宽 = `var(--chart-w)`（**禁写死 px 宽**）、高 = `var(--chart-h)`。
5. 长文本行长 ≤ 34 中文字符。
6. 目标尺寸 **375×812（基准）/ 390×844 / 414×896 / 360×800 / 320×568 兜底**，全部**无横向滚动、无溢出、无重叠**。

### 10.5 安全区 / 输入

- 底部固定区与 tabBar `padding-bottom: var(--safe-b)`。
- 表单页开启 `adjust-position` 并监听 `uni.onKeyboardHeightChange`。
- **V1.0 不做横屏。**

## 13. 交互状态底线（每页每控件逐项检查）

| 状态 | 要求 |
|---|---|
| 正常 | 有数据、在线，完整渲染 |
| 空 / 首次使用 | `AppEmpty`；首次使用多一句"为什么需要用" + 引导按钮 |
| 加载 | **骨架屏**（禁整页白屏）；> 8s 追加文案 |
| 失败 | `AppErrorState` 或 Toast + **重试入口**；局部失败只失败局部（如首页概览区） |
| 未登录 | 路由守卫 → SC-03（保留已填草稿）；**SC-23/24/25 与 SC-01/02/03/04 放行** |
| 离线 | 缓存只读 + **「离线数据 · 更新于 `<时间>`」** 标记；**写操作按钮置灰 + 明确提示**；**不自动重放** |
| 高风险 | `AppModal danger`：清空 = 文本「确认删除」+ 密码；注销 = 文本「注销账号」+ 密码 + 终局图标；删除单条 = 二次确认；批量 = 密码 + 二次确认（≥500 条追加文本） |
| 提交防重 | 点击即置灰 + loading；写操作带 `Idempotency-Key`（**不自动重试**） |
| 401 | 单次 Refresh → 重放；失败 → **清栈 `reLaunch` 到 SC-03** + 清 9 项缓存 + 取消本地通知 + 提示「登录已过期，请重新登录」 |
| 改密 / 注销成功 | **清栈 `reLaunch` 到 SC-03**（不允许返回已登出页面） |

> 本节为**底线清单**：不适用项标记 `N/A`，**不为了凑状态制造无意义 UI**（与 §8 N/A 规则一致）。
